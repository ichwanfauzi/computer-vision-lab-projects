# 👁️ Advanced Computer Vision & Image Processing Lab

> Repositori praktikum dan eksperimen komputer visi tingkat lanjut, mencakup segmentasi objek, deteksi fitur, dan penerapan model *machine learning/deep learning*.

---

## 📌 Materi & Eksperimen

- 🎯 **Object Detection & Segmentation:** Implementasi algoritma pemisahan objek dan klasifikasi bidang citra.
- 📈 **Feature Extraction:** Ekstraksi fitur visual menggunakan metode analisis tekstur dan bentuk.
- 🤖 **Computer Vision Integration:** Penggabungan OpenCV dengan pustaka analisis data untuk pengenalan pola.

---

## 🛠️ Tech Stack

- **Python 3.x** / **Jupyter Notebook**
- **Libraries:** OpenCV, NumPy, Matplotlib, Scikit-image / YOLO
